# 📝 To-Do List

A simple To-Do List web application built with HTML, CSS and JavaScript.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Press Enter to add a task
- Responsive and clean UI

## Technologies
- HTML5
- CSS3
- JavaScript

## Run
Open `index.html` in a web browser.
